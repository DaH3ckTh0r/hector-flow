# AB-123: Cache customer lookups

`GET /customers/{id}` hits the database on every call. Add an in-memory cache
in front of `ICustomerRepository.GetByIdAsync` with a configurable TTL.

## Acceptance criteria
- A second lookup of the same id within the TTL does not call the repository
- A lookup after the TTL expires calls the repository again
- The TTL is read from configuration key `CustomerCache:TtlSeconds`, default 60
- Updating a customer invalidates its cache entry
